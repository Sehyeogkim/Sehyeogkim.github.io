Claude - CLI (Code)

Date: 2026-03-06Category: Claude

Intro 글에서 Claude Code를 간단하게 소개했었다. Claude Code는 Anthropic이 개발자들을 위해 만든 CLI 기반의 Agentic AI 코딩 도구이다.
이번 글에서는 Claude CLI (Claude Code)에 대해서 설치부터 핵심 기능까지 자세하게 살펴보겠다.

Installation

Claude CLI를 설치하는 방법은 매우 간단하다. Terminal을 열고 아래 명령어를 실행하면 된다.

curl -fsSL https://claude.ai/install.sh | bash

설치가 완료되면, 터미널에서 바로 실행할 수 있다.

claude

처음 실행하면 로그인 화면이 나온다. 두 가지 인증 방식이 존재한다:

  1. 정기결제 계정 로그인 - Pro/Team/Enterprise 구독자는 바로 로그인
  2. API Key 인증 - 토큰 사용량 기반 결제 (개발자에게 추천)

API Key를 사용하려면, 환경변수를 설정해주어야 한다.

nano ~/.zshrc
export ANTHROPIC_API_KEY="sk-ant-xxxxxxx"
source ~/.zshrc

설정 후 claude를 실행하면, API Key를 인식하고 사용 여부를 물어본다.

기본 사용법

Claude CLI는 터미널에서 claude 명령어로 실행한다. 실행하면 대화형 인터페이스가 열리고, 자연어로 코딩 작업을 요청할 수 있다.

Interactive Mode (대화 모드)

claude

가장 기본적인 방법이다. 현재 디렉토리를 작업공간(Working Directory)으로 인식하고, 해당 폴더 내의 모든 파일을 읽고/수정/생성할 수 있다.

One-shot Mode (단발 명령)

claude "이 프로젝트의 구조를 설명해줘"

대화 모드에 진입하지 않고, 한 번의 질문에 대한 답변만 받고 종료하는 방식이다. 빠르게 확인할 때 유용하다.

Pipe Mode (파이프 입력)

cat error.log | claude "이 에러 로그를 분석해줘"

다른 명령어의 출력을 Claude에게 직접 전달할 수 있다. 로그 분석, 코드 리뷰 등에 활용도가 높다.

핵심 기능

Claude CLI가 단순한 챗봇이 아닌 Agentic AI인 이유는, 다양한 도구(Tools)를 자율적으로 사용하기 때문이다.

Tools (도구)

Claude CLI는 20개 이상의 내장 도구를 가지고 있다. 주요 도구들:

  • Read - 파일 읽기
  • Write - 파일 생성
  • Edit - 파일 수정 (diff 기반)
  • Bash - 터미널 명령어 실행
  • Glob - 파일 패턴 검색
  • Grep - 코드 내용 검색
  • Agent - 하위 에이전트 생성 (병렬 작업)
  • WebSearch - 웹 검색
  • WebFetch - 웹 페이지 내용 가져오기

핵심은 이 도구들을 Claude가 스스로 판단하여 사용한다는 점이다. 예를 들어, "이 프로젝트에서 사용하지 않는 함수를 찾아줘"라고 요청하면, Claude는 Glob으로 파일을 찾고, Grep으로 함수 정의와 호출을 검색하고, 분석 결과를 알려준다.

CLAUDE.md

Cowork 글에서도 다루었지만, CLAUDE.md 파일은 CLI에서도 동일하게 작동한다. 프로젝트 루트에 이 파일을 두면, Claude가 매 대화마다 이 파일을 읽는다.

# CLAUDE.md

## Project
이 프로젝트는 GitHub Pages 블로그입니다.

## Rules
- 한국어로 블로그 포스트를 작성합니다
- 이미지는 images/ 폴더에 저장합니다
- kebab-case 네이밍 규칙을 따릅니다

이렇게 프로젝트의 규칙과 컨텍스트를 정의하면, Claude가 항상 이를 참고하여 일관된 작업을 수행한다.

Context Window & Memory

Claude CLI의 Context Window는 대화가 길어지면 자동으로 이전 메시지를 압축한다. 따라서, 아주 긴 작업도 끊기지 않고 진행할 수 있다.

또한 Memory 시스템이 있어서, 사용자가 /memory 명령으로 중요한 정보를 저장할 수 있다. 저장된 메모리는 다음 세션에서도 유지된다.

작업 흐름 (Workflow)

Claude CLI로 실제 개발 작업을 할 때의 일반적인 흐름을 살펴보자.

1. 프로젝트 디렉토리로 이동

cd ~/my-project
claude

2. 작업 지시

자연어로 원하는 작업을 설명한다. Claude는 알아서 파일을 찾고, 읽고, 수정한다.

> 로그인 기능에 비밀번호 재설정 기능을 추가해줘

3. 검토 및 승인

Claude가 파일을 수정하기 전에 항상 사용자에게 확인을 요청한다. 위험한 작업(파일 삭제, git push 등)은 반드시 승인이 필요하다. 이것이 Agentic AI에서 중요한 Human-in-the-Loop 패턴이다.

4. Git 연동

Claude CLI는 Git과 자연스럽게 연동된다. 작업이 끝나면:

> 지금까지의 변경사항을 커밋해줘

Claude가 변경된 파일들을 분석하고, 적절한 커밋 메시지를 작성하여 커밋한다.

IDE 연동

Claude CLI는 터미널뿐만 아니라 IDE에서도 사용할 수 있다.

VS Code Extension

VS Code에서 Claude Extension을 설치하면, 좌측 사이드바에 Claude 대화창이 나타난다. CLI와 동일한 기능을 IDE 안에서 사용할 수 있다.

Web (claude.ai/code)

브라우저에서도 Claude Code를 사용할 수 있다. GitHub 저장소를 연결하면 웹에서 직접 코드를 수정하고 커밋할 수 있다. 터미널 접근이 어려운 환경에서 유용하다.

Slash Commands

Claude CLI에는 유용한 슬래시 명령어들이 내장되어 있다.

  • /help - 도움말 표시
  • /memory - 메모리에 정보 저장
  • /compact - 대화 내용 압축 (토큰 절약)
  • /clear - 대화 초기화
  • /cost - 현재 세션의 토큰 사용량 및 비용 확인
  • /model - 모델 변경 (Haiku, Sonnet, Opus)

특히 /compact는 대화가 길어졌을 때 컨텍스트를 압축하여 토큰 비용을 절약할 수 있어 매우 유용하다.

Permission (권한 모드)

Claude CLI는 보안을 위해 권한 시스템을 제공한다.

  • Ask mode - 모든 도구 사용 시 사용자 승인 필요 (가장 안전)
  • Auto-approve mode - 읽기 도구는 자동 승인, 수정 도구는 승인 필요
  • Full auto mode - 모든 도구 자동 승인 (주의 필요)

개인적으로 처음 사용하시는 분은 Ask mode로 시작하여, Claude가 어떤 도구를 어떤 상황에서 사용하는지 파악한 후에 Auto-approve mode로 전환하는 것을 추천한다.

Tips & 활용법

1. CLAUDE.md를 잘 작성하자

프로젝트의 구조, 네이밍 규칙, 사용하는 기술 스택, 테스트 방법 등을 CLAUDE.md에 정리하면, Claude의 작업 품질이 크게 향상된다.

2. 작은 단위로 요청하자

한 번에 큰 기능을 요청하기보다, 작은 단위로 나누어 요청하고 중간중간 검토하는 것이 좋다. 이는 실수를 줄이고 결과물의 품질을 높인다.

3. Git 브랜치를 활용하자

새로운 기능을 작업할 때는 항상 별도의 브랜치에서 진행하자. Claude가 예상치 못한 변경을 하더라도 쉽게 되돌릴 수 있다.

4. /compact를 자주 사용하자

대화가 길어지면 토큰 소비가 빠르게 증가한다. 작업 단위가 끝날 때마다 /compact를 사용하여 토큰을 절약하자.

Conclusion

Claude CLI (Claude Code)는 개발자들을 위한 가장 강력한 Agentic AI 코딩 도구 중 하나이다.

단순한 코드 자동완성을 넘어서:

  • 프로젝트 전체를 이해하고 수정
  • Git 연동을 통한 버전 관리
  • 20개 이상의 도구를 자율적으로 사용
  • 하위 에이전트를 생성하여 병렬 작업
  • CLAUDE.md 기반의 프로젝트 맞춤 설정

이러한 기능들이 Claude CLI를 단순한 코딩 보조 도구가 아닌, Agentic AI 개발 파트너로 만들어준다.

결국 핵심은, Claude CLI를 얼마나 잘 활용하느냐는 지시를 얼마나 명확하고 구조적으로 하느냐에 달려있다. 좋은 CLAUDE.md 파일, 명확한 요청, 그리고 적절한 검토 과정이 최고의 결과를 만들어낸다.
